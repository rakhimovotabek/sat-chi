# SAT’chi
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
SAT students study, solve questions, track saved learning and play academic Battles.
Administrators manage books, questions, students, homework and reporting.

## Product Purpose
Make study, saved progress and collaborative practice understandable and reliable.
Shared canonical questions preserve learning history across Books, Bank and Homework.

## Operating Context
Existing React/Vite/Supabase application; old Dell laptop with about 4 GB RAM.
This sprint is local only. No deployment, Git push, hosted changes or real student writes.

## Capabilities and Constraints
Preserve grading, saves, imports, Homework deletion, SBank identifiers, Battles scores
and reconnect behavior. Statistics must come from saved records; do not invent XP,
achievements, comparisons, ranks or time. Current hosted schema differs from local.

## Brand Commitments
SAT’chi identity; user confirmed premium academic design, softer rounded surfaces,
clean blue/white light and navy/electric-blue dark, energetic but readable Battles.
Interpret the four supplied design references together; never copy their sample data.
User explicitly selected implementation directly in the app, with working-page review.

## Accessibility & Inclusion
Reduced motion, keyboard controls, readable contrast, responsive 390/768/1366px.

## Product Principles
- Saved learning is the source of truth.
- Clear next actions precede decoration.
- Shared components keep workflows consistent.
- Short bounded motion supports comprehension without disrupting solving.
